<project_specification>
  <project_name>AMA - Autonomous Marketing Agency Platform</project_name>

  <overview>
    Build a fully functional Autonomous Marketing Agency (AMA) platform—a "Company-in-a-Box" system that acts as a 
    virtual marketing department. The application provides an interactive SaaS-style visual interface combined with 
    a "Super Agent" conversational AI that understands all system functions and can guide users or execute any 
    operation via natural language. The platform integrates the MAKER framework (Maximal Agentic Decomposition with 
    Voting) for reliable decision-making and multi-agent collaboration, backed by Git-based state management for 
    full audit trails. The system executes, learns, evolves, and self-improves through continuous optimization cycles.
  </overview>

  <key_interactions>
    <super_agent_flow>
      1. User opens Super Agent panel (or clicks floating button)
      2. Types natural language command (e.g., "Create a Black Friday campaign for Client X")
      3. Agent decomposes request into tasks using MAKER framework
      4. Agent shows proposed task breakdown and asks for confirmation
      5. User confirms, agent begins execution
      6. Real-time streaming shows agent progress and decisions
      7. Multiple worker agents execute in parallel
      8. Congress votes on creative outputs
      9. Results stream back with artifacts and deliverables
      10. Red-flags pause execution and prompt for human input
    </super_agent_flow>

    <client_onboarding_flow>
      1. Click "New Client" button
      2. Enter client URL and upload brand assets (PDFs, images)
      3. System runs brand absorption agent
      4. Agent extracts brand voice, ICP, and competitive landscape
      5. System generates initial SOP set for client
      6. User reviews and approves extracted information
      7. System creates client workspace with all directories
      8. Client appears in dashboard ready for campaign creation
    </client_onboarding_flow>

    <campaign_creation_flow>
      1. Select client, click "New Campaign"
      2. Wizard guides through angle development and offer structuring
      3. System generates multiple angle options via Congress voting
      4. User selects winning angles
      5. System generates creative briefs for all formats
      6. Parallel agents produce copy variations
      7. Congress votes on best options
      8. User reviews and approves final assets
      9. Technical setup wizard (pixel, audiences, budget)
      10. Launch checklist validation
      11. Campaign goes live with tracking enabled
    </campaign_creation_flow>

    <optimization_loop>
      1. System automatically pulls performance data (24h cycle)
      2. Analyst agent identifies winners and losers
      3. Dashboard updates with recommendations
      4. System generates iteration briefs for winning ads
      5. Underperformers auto-paused (or flagged for review)
      6. Market intel agent checks for new competitor trends
      7. New tasks auto-generated based on insights
      8. Performance memory updated with learnings
    </optimization_loop>
  </key_interactions>
